# Site Institucional LUBESNI

Site estático responsivo preparado como **dossiê institucional digital** e base para comprovações futuras.

## Estrutura
- `index.html` — página inicial
- `historia.html` — trajetória e linha do tempo
- `projetos.html` — executados x em estruturação
- `agremiacoes.html` — diretório das 14 agremiações ativas
- `agremiacao-*.html` — páginas individuais das escolas, afoxés, blocos e maracatus ativos
- `acervo.html` — comprovações e links
- `contato.html` — dados institucionais
- `assets/docs/portfolio-lubesni.pdf` — portfólio-fonte
- `assets/images/` — imagens originais extraídas do portfólio

## Publicação
Pode ser publicado em hospedagem comum, Netlify, Cloudflare Pages, GitHub Pages ou no domínio institucional.

## Regra de atualização
Para cada nova ação, registrar:
1. data e local;
2. nome do projeto;
3. parceiros e apoiadores;
4. fotos originais;
5. link público;
6. arquivo comprobatório (PDF/ata/certificado);
7. status: EXECUTADO ou EM ESTRUTURAÇÃO.

### Atenção
A atualização institucional de agosto de 2026 informa 14 agremiações ativas, distribuídas entre escolas de samba, afoxés, blocos e maracatus. O site deve ser atualizado sempre que houver mudança formal de filiação, preservando também os registros históricos do acervo.
